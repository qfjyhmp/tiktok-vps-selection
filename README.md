## 机房 IP、原生 IP、双 ISP：美国节点为什么也会 0 播放

TikTok 判断一个账号像不像真人，IP 类型排在第一位。业内通行的三层划分是：机房 IP 直接出局，原生 IP 是及格线，住宅 IP 或双 ISP 才是能长期养号的那一档。

机房 IP 归属显示为某个数据中心或云服务商，TikTok 识别这类网段很准，轻则限流，重则封号，几十块一年的廉价 VPS 基本都在这层。原生 IP 指 IP 注册地和机房所在国一致，比如机房在洛杉矶、whois 显示美国，平台会把你当成本地上网的用户，这是做美区的最低门槛。第三层是住宅 IP 或双 ISP，IP 归属挂在本土运营商名下，看起来就是一个住在加州的普通宽带用户。

WePC 这条产品线的命名全部围绕这个划分：官网美国四款写的都是“家宽双 ISP”，英国、日本、韩国、马来西亚、新西兰等地区标“原生家宽”，英国和德国那两款 AUD 10.90 则老实写了“非家宽 IP”。

美区号 0 播放，除了 IP 类型，还有两个常见原因。一是 IP 段被前面的人用脏了，同一个段上有人跑过违规业务，整段都会被平台盯上，这也是 GTT/NTT 款强调 216/192 网段的意义。二是环境不一致：IP 在洛杉矶，手机时区设成东八区、系统语言是中文，平台会直接把账号判成异常。这三件事里，只有第一件能靠换机器解决。
